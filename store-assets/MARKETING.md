## Elevator pitch (~60 words)

Easy Annotation turns any live webpage into a marked-up review. Click to drop
numbered circles, drag to outline areas, rate each issue Low/Medium/High, and
comment by typing or talking — with one-click on-device AI cleanup. Then
export a single HTML file: a full-page screenshot with your badges in place,
beside every comment. No accounts, no servers, nothing leaves your machine.

## Ten-second demo script

"Watch: I click the icon, click the broken button — that's issue 1. I drag
around the misaligned header — issue 2, marked High. I talk instead of typing,
hit Tidy, and it reads like I wrote it carefully. Export. That file is the
whole review — screenshot, numbers, comments — and it opens in any browser."

## Feature → benefit copy

Use these pairs anywhere features get listed; lead with the benefit.

| Feature | Benefit-led copy |
|---|---|
| Numbered markers on the live page | "Issue 3" means one exact spot — no more 'the button near the top.' |
| Severity colors | The red things get fixed first. Triage happens at a glance, not in a meeting. |
| Voice dictation + on-device Tidy | Say it fast, publish it clean. The AI cleanup runs on your machine — nothing is uploaded. |
| Full-page export | One HTML file is the entire review. Slack it, email it — it opens anywhere, forever. |
| Marking on/off toggle | Review and browse the same page without closing anything. |
| Per-page autosave | A half-finished review survives the tab, the restart, and the weekend. |
| No accounts, no servers | Nothing to sign up for, nothing to leak. It works on day one and on the intranet. |

## Boilerplate (About)

Easy Annotation is a Chrome extension for annotating live webpages. Reviewers
drop numbered, severity-rated markers directly on the page, comment by
keyboard or voice, and export self-contained HTML reports that pair a
full-page screenshot with every comment. All data — annotations, screenshots,
and AI-assisted text cleanup — is processed and stored locally on the user's
machine.

## Copy rules

- Numbers and names are load-bearing: "one HTML file," "Low/Medium/High,"
  "on-device." Don't blur them into "seamless" or "powerful."
- Never claim cloud sync, team accounts, or hosted anything — the privacy
  story *is* the differentiator, and the store disclosures depend on it.
- "On-device AI" only ever refers to Chrome's built-in model. If a cloud AI
  option ships later, every piece of copy above needs revisiting — grep this
  file and STORE_LISTING.md for "on-device" and "leaves your machine."
